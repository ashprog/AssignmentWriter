# Assignment Writer

Assignment Writer is an Android application designed to convert digital text into a natural-looking handwritten format. It's perfect for students or anyone who needs to submit "handwritten" assignments while typing them out.

## Features

- **Text to Handwriting:** Convert typed text into handwriting using various pre-loaded fonts or your own custom handwriting font.
- **Custom Fonts:** Supports `.otf` font files for a truly personalized look.
- **Adjustable Styling:** 
    - Change font size and line spacing.
    - Choose between different "ink" colors (e.g., Blue, Black).
    - Select from different paper backgrounds (e.g., Ruled, Plain).
- **Special Tags:** Use `<Q>` tags to highlight question text in a different color.
- **Export to Image/PDF:** 
    - Save individual pages as PNG images.
    - Built-in PDF converter to bundle your "handwritten" pages into a single PDF document.
- **Privacy Focused:** Does not use Advertising ID or track user data.

## How to Use

1. **Type your text:** Enter the assignment content in the editor.
2. **Customize:** Go to Settings to adjust the font, size, color, and background to match your requirements.
3. **Save Page:** Tap the download icon to save the current screen as a PNG image.
4. **Convert to PDF:** Use the PDF Converter feature to select your saved images and generate a single PDF file.

## Technical Details

- **Minimum SDK:** 21 (Android 5.0 Lollipop)
- **Target SDK:** 35 (Android 15)
- **Key Libraries:** 
    - `androidx.appcompat`: For standard UI components.
    - `com.google.android.material`: For Material Design components.
    - `com.itextpdf:itextg`: For generating PDF files.

## Privacy Policy

This app does not collect any personal information or use the Google Advertising ID. All processing happens locally on your device.
